## What happened

The console began here as its own repository. It moved into the main repository so that a change spanning the gateway and the console is one pull request. Its git history came with it, so nothing is lost by going there.

The container image keeps its old name, `ghcr.io/almadon/novak-konzol`, and is now built from `console/` in the main repository.
